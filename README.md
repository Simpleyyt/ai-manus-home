## About AI Manus

**AI Manus** is a general-purpose AI Agent system that supports running various tools and operations in a sandbox environment. Enjoy your own intelligent assistant with AI Manus!

**Key Features:**

- Minimal deployment — only an LLM service required, no other external dependencies
- Supports Terminal, Browser, File, Web Search tools with real-time viewing, and external MCP tool integration
- Each task runs in a dedicated sandbox within a local Docker environment
- Session history management, background tasks, file upload and download
- Multilingual support (Chinese & English)
