Capabilities

关键能力覆盖真实生产环境

最小依赖部署

仅依赖 LLM 服务即可运行，无需复杂外部服务堆栈。

完整工具系统

内置 Terminal、Browser、File、Web Search、消息工具并支持 MCP 扩展。

任务级沙箱隔离

每个任务独立容器环境，浏览器与命令执行互不干扰，安全可控。

会话与后台任务

会话历史可持久化管理，支持任务中断、恢复与后台执行。

实时查看与接管

可实时观察 Agent 执行过程，并在关键节点手动接管操作。

多语言与认证

支持中英文界面，并提供用户登录与认证机制。

Architecture

清晰的 Agent + Sandbox 架构设计

前端通过会话与服务端通信，服务端分配沙箱并驱动 PlanAct Agent，通过事件流将执行状态实时回传前端。

Quick Start

几分钟启动你的 AI Manus

推荐使用 Docker Compose 部署，拉起前后端及沙箱镜像即可运行。

阅读部署文档 先试用 Demo 
git clone https://github.com/simpleyyt/ai-manus.git
cd ai-manus
cp .env.example .env
docker compose up -d
