工作原理

只需一句话，Agent 自动规划、执行、调用工具，将您的想法变成现实

步骤 1

任务分解

PlanAct Agent 分析用户请求，制定计划并拆分为可执行的步骤

步骤 2

Agent 执行

Agent 按照计划逐步执行，自主完成各阶段任务

步骤 3

工具调用

Agent 调用浏览器、Shell、文件等工具完成研究、分析与创作

步骤 4

结果汇总

Agent 整合执行结果，通过 SSE 实时回传，完成最终答复

常见问题

部署 AI Manus 需要哪些基础条件？

最小只需一个 LLM 服务即可完成部署，不需要依赖任何其他外部服务。内置 Terminal、Browser、File、Web Search 等工具，开箱即用，非常适合个人或团队快速上手。

沙盒隔离是如何工作的？

每个 Task 都会分配一个独立的沙盒，运行在本地 Docker 环境中，相互之间完全隔离，确保任务安全、稳定地执行，不会相互干扰。

支持哪些工具？可以实时查看吗？

支持 Terminal、Browser、File、Web Search 和消息工具。所有工具均支持实时查看——你可以随时观察 Agent 的执行过程，并在需要时接管操作。

任务执行过程中可以中断吗？

支持随时停止与打断，也支持文件上传与下载。任务会话通过 MongoDB/Redis 管理，支持后台长任务，即使关闭页面任务仍会继续运行。

AI Manus 支持私有化部署吗？

完全支持。AI Manus 是开源项目，可完全私有化部署在自己的服务器上。每个服务与工具都包含 Built-in 版本，数据不会流出，满足企业级安全与合规要求。

想自部署 AI Manus？

开源可自部署，最小只需一个 LLM。立即体验 Demo 或前往 GitHub 参与贡献。
