## 关于 AI Manus

**AI Manus** 是一个通用的 AI Agent 系统，支持在沙盒环境中运行各种工具和操作，用 AI Manus 开启你的智能体之旅吧！

**主要特性：**

- 极简部署，最小只需一个 LLM 服务即可，无需依赖其他外部服务
- 支持 Terminal、Browser、File、Web Search 工具，支持实时查看和接管，支持外部 MCP 工具集成
- 每个任务分配独立沙盒，在本地 Docker 环境中运行
- 支持会话历史管理、后台任务、文件上传与下载
- 支持中文与英文双语
